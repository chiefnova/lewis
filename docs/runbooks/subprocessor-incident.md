# Subprocessor Incident Runbook

Use this when a vendor may have received PHI or operational data outside the approved posture in `docs/subprocessors.md`.

1. Freeze the integration or affected export path.
2. Preserve logs and configuration evidence without adding PHI to new systems.
3. Identify affected tenants, data classes, timestamps, and vendor systems.
4. Notify counsel and security owner.
5. Determine whether the vendor had an executed BAA and whether the data was within approved scope.
6. Open patient/tenant disclosure workflows if counsel determines notification is required.
7. Record the incident, corrective actions, and subprocessor review update.
